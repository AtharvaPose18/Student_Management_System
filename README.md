## Description
A simple Java-based Student Management System that allows users to manage student records using an ArrayList. It provides options to add, view, search, delete students, and update their marks.

## Features
- Add new student records
- View all students
- Search students using roll number
- Delete student records
- Update student marks
- Prevent duplicate roll numbers
- Validate student names, roll numbers, and marks
- Handle invalid input using exception handling

## Technologies Used
- Java
- ArrayList
- Scanner
- Exception Handling

## How to Run
1. Download or clone this repository.
2. Open a terminal in the folder containing StudentManagementSystem.java.
3. Compile the program:
   javac StudentManagementSystem.java
   
4. Run the program:
   java StudentManagementSystem
